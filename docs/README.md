### Setup / Deployment

1. Fork or clone this repository to your GitHub username profile repo (`username/username`)
2. Replace `abhirajsingh524` with your GitHub username in all workflow files
3. Add a `METRICS_TOKEN` secret in repo settings for metrics workflow
4. Push — GitHub Actions will auto-run `snake.yml` and `metrics.yml`
5. Update `assets/identity/profile.png` with your actual photo
6. Update contact links in `README.md`

### GitHub Actions Secrets Required

| Secret | Purpose |
|--------|---------|
| `GITHUB_TOKEN` | Auto-provided — snake animation, releases |
| `METRICS_TOKEN` | Personal Access Token — GitHub metrics generation |
